## [Unreleased]

### Added
- Data phase database schema: 18 migrations defining tables for cards, card types, classes, talents, keywords, heroes, hero profiles, card printings, card legality, precons, rules text versions, errata bulletins, meta snapshots, and staple stats, with foreign keys, indexes, and constraints. Includes a feature test validating the full schema (#10).
- `php artisan data:ingest-cards` command to ingest Flesh and Blood card data from the-fab-cube/flesh-and-blood-cards, populating cards, card types, classes, talents, keywords, legality, and hero/hero profile seed rows via idempotent upserts keyed on a new `cards.source_id` column (#11).
- `php artisan data:ingest-pricing` command to refresh market pricing from tcgcsv.com per-set CSV data, updating `card_printings.price_cache` and `price_updated_at` by matching the printed card number against `cardvault_print_id`, with a `--category` option for per-category ingestion. Adds the supporting `CardPrinting` model and `CardFactory`/`CardPrintingFactory` factories (#12).
- `php artisan data:ingest-printings` command to ingest card print variations (set code, rarity, finish, art variant, cardvault print ID) from the unofficial cardvault API by matching existing cards by exact name, automatically mirroring art to DigitalOcean Spaces as optimized WebP, with a new `card_printings.image_source_hash` column enabling idempotent re-runs (#13).
- `php artisan data:ingest-rules-text` command to fetch the Comprehensive Rules plain-text file from rules.fabtcg.com and insert a versioned snapshot into `rules_text_versions`, computing `diff_from_previous` (added/removed/changed rule-section keys) on every run without overwriting prior versions. Adds the `RulesTextVersion` model and factory (#14).
- `php artisan data:ingest-errata` command to scrape the fabtcg.com errata bulletins index and populate `errata_bulletins` with each bulletin's number, URL, published date, and article content, resolving `affected_card_ids` by matching article headings against card names case-insensitively. Bulletins are cached once and never re-scraped — only the index is re-checked for new entries — and articles that don't match the expected page structure are flagged and skipped rather than persisted partially. Adds the `ErrataBulletin` model and factory (#15).
- `php artisan data:ingest-meta` command to ingest hero win-rate and sample-size data from fabtcgmeta.com (JSON API) and fablazing.com (React Router SSR payload) into meta_snapshots, resolving each observation against existing hero-type cards and canonicalizing formats (CC, LL, SAGE, GAGE) from the formats table at runtime. Adds the MetaSnapshot model, MetaSnapshotFactory, and hero() state on CardFactory (#16).
- `php artisan data:ingest-staples` command to scrape per-hero card inclusion-rate stats from fabrec.gg (`/hero/{slug}` pages) into staple_stats, resolving hero cards by card_type_id and other cards by case-insensitive name match, with updateOrCreate keyed on hero_id/card_id/source and flag-and-skip handling for fetch failures, malformed rows, and unmatched card names. Adds the StapleStat model and StapleStatFactory; uses native PHP 8.4 Dom\HTMLDocument/Dom\XPath without adding new Composer dependencies (#17).
- `php artisan data:ingest-hero-selection` command to ingest official hero playstyle tags, lore, and format legality from fabtcg.com/hero-selection JSON API into hero_profiles, heroes, and card_legality, resolving each fabtcg hero against hero-type cards by case-insensitive name match, with HTML entity decoding/whitespace normalization of bio text and mapping of fabtcg format keys (cc, living-legend, project-blue) to canonical abbreviations (CC, LL, SAGE) — unmapped keys (blitz, commoner, ultimate-pit-fight) are flagged once per run but not written. As an official-source overlay, it overwrites IngestFabCubeCards legality entries for the three mapped formats without deleting rows, with flag-and-skip handling for unmatched heroes, missing profiles, empty tags/bios, unseeded formats, and unrecognized statuses. Adds the IngestHeroSelectionMetadataCommandTest feature test and fabtcg-hero-selection.json fixture (#18).
